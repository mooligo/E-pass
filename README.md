# E-pass
为MCU添加3个引脚：
PA10——PWR_EN
电池供电模式：
当 USB 断开，D3 截止，Q2 栅极由 PWR_EN 控制：
PWR_EN = 高：Q2 导通 → Q1 栅极接地 → Q1 导通 → 电池供电给系统
PWR_EN = 低：Q2 截止 → Q1 栅极被 R5 上拉到 BAT_IN → Q1 关断 → 系统断电

PA0——EC_KEY_DET
1. 按键未按下时
EC_KEY 悬空（高阻），BAT 电压（约 3.7V）通过 U5 正向导通，给 EC_KEY_DET 提供高电平。
此时 MCU 读取到的 EC_KEY_DET 为高电平，判断为按键未按下。
2. 按键按下时
EC_KEY 直接接地，电位变为 0V。
U5 反向截止，U6 正向导通，EC_KEY_DET 被拉低到接近 0V。
此时 MCU 读取到的 EC_KEY_DET 为低电平，判断为按键按下。

PB14——ST25_GPO
GPO 中断信号
ST25 的 GPO（7 脚） → 接 STM32 的 PB14（27 脚）
作用：ST25 检测到 NFC 读写器时，通过该引脚给 MCU 发中断信号，实现快速唤醒。
不接也能基础通信，但无法用中断方式检测标签。




电源电路工作流程：
前置说明：
电池正极 → BAT_IN，电池负极 → 公共 GND；
MCU 后备脚 VBAT、主电源 BAT、系统 3.3V、5V 输入为四大电源分支。
一、仅装电池、未按按键（关机 / 待机状态）
BAT_IN 常驻 3.0~4.2V（电池电压），全程不受开关机控制。
VBAT 支路：
BAT_IN → 1N5819 肖特基二极管 → VBAT
只要电池在，VBAT 一直有电，持续给 MCU 的 RTC、备份寄存器供电，时钟 / 备份数据不掉电。
主开关支路（Q1+Q2）：
Q1 (P 沟道 MOS) 栅极被上拉，Q1 截止 → BAT = 0V
后级 LDO 无输入，MCU 主 3.3V 电源断开，整机功能区不工作。
无 5V 输入，充电芯片不工作，充电灯灭。
二、短按按键 SW4（开机过程）
按键按下，电平被拉低，MCU 检测到按键触发信号。
MCU 输出 PWR_EN 高电平。
通路：PWR_EN / +5V（或门逻辑）→ 二极管 → Q2 (N 沟道 MOS) 栅极
→ Q2 导通，把 Q1 栅极拉到接近 GND。
P 沟道 Q1 满足导通条件 → Q1 导通。
BAT_IN → Q1 → BAT 上电，电压≈电池电压。
BAT 给 LDO (LP5907) 供电，LDO 输出稳定 3.3V，MCU 及外设正式启动。
松开按键：MCU 持续保持 PWR_EN 高电平，维持整机开机状态。
同时 BAT 经 R6/R7 分压得到 BAT_DET，MCU 实时采集电池电压。
三、开机后正常运行（纯电池供电，无外接 5V）
BAT_IN、VBAT、BAT、3.3V 全部正常带电。
RTC 由 VBAT 独立供电，主逻辑、外设由 3.3V 供电。
充电芯片 MCP73831 无 5V 输入，不工作，充电指示灯熄灭。
四、开机状态下，外接 USB/5V 电源（充电 + 同时工作）
+5V 接入后，供电分为两路：
一路参与开关机逻辑，辅助维持 Q2 导通，整机不掉电；
一路送入 MCP73831 充电芯片。
充电芯片启动，对 BAT_IN 端的锂电池恒流 + 恒压充电。
充电时 STAT 引脚拉低 → 充电 LED 点亮，同时 BAT_CHG_DET 反馈状态给 MCU。
电池充满后，充电停止，LED 熄灭。
整机依旧由 BAT → LDO → 3.3V 正常运行，互不干扰。
五、再次短按按键 SW4（关机过程）
MCU 检测到关机按键信号。
MCU 拉低 PWR_EN。
Q2 栅极失去高电平 → Q2 截止。
Q1 栅极恢复高电位 → Q1 截止。
BAT 断电至 0V，LDO 停止输出，MCU 主电源断开，整机功能关闭。
回到待机状态：仅 BAT_IN、VBAT 保持有电，RTC 继续运行。
极简速记版（方便背诵 / 复盘）
只装电池：VBAT 常电（RTC 工作），BAT 无电，整机关机；
按开机键：MCU 输出使能→两级 MOS 导通→BAT 上电→LDO 出 3.3V，整机启动；
外接 5V：充电芯片工作，边用边充；
按关机键：撤销使能→MOS 断开→BAT 断电，仅 VBAT 保留供电。
