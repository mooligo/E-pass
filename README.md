# 电路工作说明
## 引脚定义
- **PA10 — PWR_EN**
  电源使能控制引脚，用于控制系统供电通断。
- **PA0 — EC_KEY_DET**
  按键检测引脚，用于判断开关机按键状态。
- **PB14 — ST25_GPO**
  NFC 中断信号引脚，用于快速唤醒 MCU。

## 引脚功能说明
### PA10 — PWR_EN（电池供电模式）
当 USB 断开时，D3 截止，Q2 栅极由 PWR_EN 控制：
- **PWR_EN = 高电平**：Q2 导通 → Q1 栅极接地 → Q1 导通 → 电池为系统供电
- **PWR_EN = 低电平**：Q2 截止 → Q1 栅极经 R5 上拉至 BAT_IN → Q1 关断 → 系统断电

### PA0 — EC_KEY_DET（按键检测）
1. **按键未按下**
   EC_KEY 呈高阻态，BAT 电压（约 3.7V）经 U5 正向导通，为 EC_KEY_DET 提供高电平。
   MCU 读取为高电平，判定按键未按下。
2. **按键按下**
   EC_KEY 直接接地，电位为 0V。
   U5 反向截止、U6 正向导通，EC_KEY_DET 被拉低至接近 0V。
   MCU 读取为低电平，判定按键按下。

### PB14 — ST25_GPO（NFC 中断）
- 连接关系：ST25 的 GPO（7 脚） → STM32 的 PB14（27 脚）
- 功能：ST25 检测到 NFC 读写器时，通过该引脚向 MCU 发送中断信号，实现快速唤醒
- 备注：不连接可基础通信，但无法通过中断方式检测标签

## 整体工作流程（单节 3.7V 锂电池系统）
### 前置说明
- 电池正极 → BAT_IN，电池负极 → 公共 GND
- 核心电源分支：MCU 后备电源 VBAT、系统主电源 BAT、系统 3.3V、5V 输入

### 一、仅装电池、未按按键（关机/待机状态）
1. BAT_IN 持续输出 3.0~4.2V（电池电压），不受开关机控制
2. VBAT 支路：BAT_IN → 1N5819 肖特基二极管 → VBAT
   只要电池接入，VBAT 持续供电，保证 MCU RTC 时钟、备份寄存器数据不丢失
3. 主开关支路（Q1+Q2）：Q1 截止 → BAT = 0V → LDO 无输入 → MCU 主电源断开
4. 无 5V 输入，充电芯片不工作，充电指示灯熄灭

### 二、短按按键 SW4（开机过程）
1. 按键按下，电平拉低，MCU 检测到按键触发信号
2. MCU 输出 PWR_EN 高电平
3. 信号通路：PWR_EN / +5V → 二极管 → Q2 栅极 → Q2 导通 → Q1 栅极接地
4. Q1 导通，BAT_IN → Q1 → BAT 上电，电压约等于电池电压
5. BAT 为 LDO（LP5907）供电，LDO 输出稳定 3.3V，MCU 及外设启动
6. 松开按键后，MCU 保持 PWR_EN 高电平，维持系统开机
7. BAT 经 R6/R7 分压生成 BAT_DET，MCU 实时采集电池电压

### 三、开机后正常运行（纯电池供电，无外接 5V）
1. BAT_IN、VBAT、BAT、3.3V 均正常供电
2. RTC 由 VBAT 独立供电，主逻辑与外设由 3.3V 供电
3. 充电芯片 MCP73831 无 5V 输入，不工作，充电指示灯熄灭

### 四、开机状态外接 USB/5V 电源（充电+系统工作）
1. +5V 分为两路：一路维持 Q2 导通，保证系统不掉电；一路输入 MCP73831 充电芯片
2. 充电芯片启动，以恒流+恒压方式为 BAT_IN 端锂电池充电
3. 充电中：STAT 引脚拉低 → 充电 LED 点亮，BAT_CHG_DET 反馈状态至 MCU
4. 电池充满：充电停止，LED 熄灭
5. 系统持续由 BAT → LDO → 3.3V 供电，充电与工作互不影响

### 五、开机状态短按按键 SW4（关机过程）
1. MCU 检测到关机按键信号
2. MCU 拉低 PWR_EN 电平
3. Q2 栅极失电 → Q2 截止 → Q1 截止
4. BAT 断电至 0V → LDO 停止输出 → MCU 主电源断开，系统关闭
5. 回归待机状态：仅 BAT_IN、VBAT 带电，RTC 正常运行

## 极简工作流程速记
- 只装电池：VBAT 常电（RTC 工作），BAT 无电，系统关机
- 按开机键：MCU 输出使能 → 两级 MOS 导通 → BAT 上电 → LDO 输出 3.3V，系统启动
- 外接 5V：充电芯片工作，边使用边充电
- 按关机键：撤销使能 → MOS 关断 → BAT 断电，仅 VBAT 保持供电

## 关键电源节点说明
- **BAT_IN**：电池正极输入，3.0~4.2V
- **BAT**：系统主电源，开机≈BAT_IN，关机=0V
- **VBAT**：MCU 后备电源，比 BAT_IN 低 0.2~0.4V，持续供电
